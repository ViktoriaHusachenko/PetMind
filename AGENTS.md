# Технологічний стек

Стек монорепозиторію відповідає таблиці 3.4 КРМ і є обов'язковим орієнтиром для наступних змін.

| Частина | Технології та правила |
|---|---|
| Монорепозиторій | Ядро методу розташоване в `src/petrec/` і вже реалізоване. Його не переписувати. `backend/` містить API на FastAPI і лише імпортує `petrec`; `frontend/` містить вебклієнт; `docker-compose.yml` описує локальне розгортання. |
| Backend | Python 3.11, FastAPI, Pydantic, SQLAlchemy 2 та psycopg. База даних — PostgreSQL із розширенням pgvector; векторні поля зберігаються в тій самій БД. Для планових задач використовувати APScheduler. LLM-агент — власний цикл на основі виклику функцій, без LangGraph. |
| Frontend | React 19, TypeScript, Vite 8 і Tailwind CSS v4 через `@tailwindcss/vite`. Не створювати `tailwind.config` або `postcss.config`. Єдина дозволена додаткова залежність — `react-router-dom`; не додавати UI-бібліотеки чи менеджери стану. Дані отримувати через `fetch`, стан компонента вести через `useState`/`useEffect`. Рядки з апострофами записувати в подвійних лапках. Компоненти оголошувати з `default export`. |
| Бренд та інтерфейс | Назва вебзастосунку — «PetMind». Інтерфейс українською мовою, валюта — ₴. |
| Безпека рекомендацій | Мітку «Без алергенів» і відсоток сумісності обчислює лише детермінований код за `Safe` та `s_final`. Ніколи не брати ці значення з тексту чи тверджень LLM. |
| Розгортання | Docker Compose із сервісами `db`, `backend` і `frontend`. |
